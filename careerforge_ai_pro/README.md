# CareerForge AI Pro – Ultimate Interview Readiness Analyzer

## Overview
CareerForge AI Pro is an advanced AI-powered platform that helps students assess and improve their interview readiness in under two minutes. It analyzes resumes, technical skills, communication, confidence, portfolio, GitHub, LinkedIn, certifications, and more, generating a comprehensive Interview Readiness Score and personalized recommendations.

## Features
- Resume and ATS analysis
- Technical, communication, and confidence assessment
- Portfolio, GitHub, and LinkedIn evaluation
- Camera and voice-based analysis
- AI mock interview simulator
- Dream company readiness and success prediction
- Personalized learning roadmap and improvement suggestions
- Gamification and recruiter dashboard
- Downloadable PDF report and QR sharing

## Setup Instructions
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `streamlit run app.py`

## Project Structure
- `app.py`: Main Streamlit app
- `modules/`: All analysis and utility modules
- `data/`: Sample resumes and datasets
- `assets/`: Images, icons, and static files

## Requirements
- Python 3.8+
- All dependencies in `requirements.txt`
